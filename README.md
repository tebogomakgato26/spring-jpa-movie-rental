# Spring JPA Movie Rental

A Java and Spring Data JPA project created to practice software design patterns and repository concepts.

## Features

- Domain Class (Movie)
- Builder Pattern
- Factory Pattern
- Helper/Utility Validation
- Spring Data JPA Repository

## Entity

### Movie

| Attribute | Type |
|------------|--------|
| movieId | String |
| title | String |
| genre | String |
| rentalPrice | double |

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Maven
- IntelliJ IDEA
- Git & GitHub
